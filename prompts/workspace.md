# Workspace

Use this prompt to start or resume SmartPoints work.

1. Read `AGENTS.md`, `docs/plans/IMPLEMENTATION-STATUS.md`, the relevant product/architecture documents, and the approved plan when one exists.
2. Inspect `git status --short`; preserve unrelated user changes.
3. Confirm the active feature, its approval state, dependencies, and next dependency-ready task.
4. Do not install dependencies, edit code, run migrations, create branches, or deploy during startup alone.
5. Report the active scope, plan/status paths read, uncommitted-state risk, and the recommended next action.

For any AI-originated product or implementation decision, use `grill-me` first. Lead with Recommendation, Why, Trade-off, then Decision needed.
